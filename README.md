# Groundglass

Site for **Groundglass: Manual Camera** (`vn.fighttech.groundglass`), a manual stills camera
for Android published by FightTech VN — <https://trunghieuvn.github.io/groundglass/>.

Plain HTML, no build step. GitHub Pages serves this repo from `main`, so every path here is
relative and the site lives on a project subpath.

* `privacy.html` — the privacy policy the Google Play listing points at
* `terms.html`, `support.html`

**This repo is a publish target, not the source of truth.** The pages are edited in
`filmode-android/web-groundglass/` and copied here; change them there, or the next deploy
will overwrite what you wrote.
